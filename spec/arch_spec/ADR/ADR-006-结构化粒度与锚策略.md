# ADR-006: 结构化粒度（Q4）与锚策略

## Status
Accepted（2026-09-16）

## Context
节点最小粒度决定：节点总量（B10 估算基准）、解析器复杂度、引用粒度、渲染还原精度。语料实测：标题 5,954、重复标题普遍（CXL「Test Steps:」×219）、含无编号标题；锚同时用作人类可读引用与（UUID 外的）稳定 alias。

## Decision
1. **最小节点 = 条款（clause）级**：按章节标题树切分；条款内段落/列表/内联标记作为该节点 `content` 的子结构（不单独成节点）。表格/图/代码块为其所在条款的**独立原子**（同级节点），不并入条款 content。

   > **实现裁决（2026-09-16，M03 落地后修正）**：**列表亦为独立原子**（`atom_type='note'`，`format='md'`），不并入条款 content。理由：(a) 列表是**频繁修改对象**，独立成节点才能被单独批注/版本化；(b) 避免 clause fragment 因内嵌长列表退化为大文本块；(c) 实测节点数 **10,271**，与原估算 9.4k 同量级（集成测试基线固定为 9k–12k）。**本裁决优先于上文「段落/列表作为子结构」的字面表述**（ADR 内的决策可被后续实现裁决修订，修订记录即本条）。

   > **落地实测**：7 份语料 = 34,986 块 → **规则覆盖率 0.9994**，零静默丢弃（34,964 承接 + 22 兜底），每块原文逐字节保留（P4 全量验证）。原子分布：clause 5,695 / table 2,440（= 源 `<table>` 数，逐档相等）/ figure 1,019 / note 748 / definition 297 / cross_ref 43 / example 20 / code 9。
2. **锚策略**：`<doc_id>#<章节号路径>·<slug(title)>`；重复标题（同父同题）加「**正文摘要** sha256[:8]」消歧；正文亦相同者加「同级序号」；无编号标题用「标题 slug + 哈希」。稳定性表述：**仅依赖文档内容与同级计数**（同一源文档重复解析逐字节一致；重排/重导入不漂移）；改版时按 (章节号路径, slug) 匹配 + 人工确认迁移。

## Trade-offs
| 维度 | 条款级（采用） | 段落级 | 文档级 |
|---|---|---|---|
| 节点数（7 份语料） | ≈9.4k（实测最小原子） | ×2–3（超 B10 原值） | 7 |
| 引用粒度 | 适中（规范引用惯用条款号） | 过细（引用噪音） | 太粗 |
| 解析复杂度 | 中（标题树 + 块归类） | 高（段落语义切分） | 低 |
| 渲染还原 | 高（结构对齐源文档） | 中 | 低（失去结构） |

## Consequences
- Positive：与规范文档的引用习惯（章节号）一致；B10 估算有据；E7 锚稳定性规则可直接落地。
- Negative：长条款（如 PCIe 大章）节点 `content` 较大（JSONB ok）；更细粒度查询需内容内检索（FTS 覆盖）。
- Risks：源文档改版重解析 → 锚匹配 + 人工确认迁移（design_doc §5.4 已定）。

## Alternatives Considered
| 方案 | 优点 | 缺点 | 放弃理由 |
|---|---|---|---|
| 段落级 | 引用最精确 | 节点数爆炸；与规范引用习惯不符 | B10/成本 |
| 混合（条款 + 关键段落提级） | 灵活 | 规则复杂、不稳定 | 复杂度不换收益；后续可增量提级 |
