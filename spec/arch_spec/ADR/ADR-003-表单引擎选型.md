# ADR-003: 表单引擎选型（Q3）

## Status
Accepted（2026-09-16）

## Context
M08 需「schema → 自动生成编辑表单」（v0.1 §5.1）：8 类原子 + 变体，节点 `content` 为 JSONB（各原子 JSON Schema 不同）；需定制 widget（HTML 片段编辑器、表格结构编辑、锚只读展示）。候选：RJSF、JSON Forms、轻量自研。

## Decision
采用 **RJSF（@rjsf/core）** 为表单引擎底座 + 定制 widgets（html-fragment / table-editor / anchor-view）；schema 直接从 M01 `schemas` 表加载。

## Trade-offs
| 维度 | RJSF（采用） | JSON Forms | 轻量自研 |
|---|---|---|---|
| 成熟度/生态 | 高（下载量最大） | 中 | — |
| JSON Schema 支持 | 原生 | 原生（含 UI Schema 概念） | 自实现 |
| 自定义 widget | 成熟机制 | 成熟 | 全自由 |
| 学习/维护成本 | 低（Agent 熟悉度 ★★★★★） | 中 | 高（长期） |
| 绑定 UI 库 | 需选主题（shadcn/antd 定制） | 绑定较松 | — |

## Consequences
- Positive：8 类原子零手写表单；新增类型仅注册 schema。
- Negative：RJSF 主题与自定义 widget 的样式定制工作（一次投入）。
- Risks：RJSF 对 `oneOf/anyOf` 复杂条件表单支持一般 → 用「每原子独立 schema + 变体用枚举字段」规避。

## Alternatives Considered
| 方案 | 优点 | 缺点 | 放弃理由 |
|---|---|---|---|
| JSON Forms | 框架无关核心 | 生态小于 RJSF；模板抽象更重 | 收益不显著 |
| 轻量自研 | 完全贴合 | 长期维护成本高（校验/联动/无障碍） | 违背「不重复造轮子」；RJSF 已满足 |
